# AI English · 发音训练

面向有大学英语基础、想恢复 AI 应用开发英语的免费手机网页。当前有四课、20 个词和四句工作场景跟读内容。

## iPhone 使用

1. 用 Safari 打开已发布的 HTTPS 地址。
2. 点击“分享”→“添加到主屏幕”，之后从主屏幕打开。
3. 先听单词和例句，再跟读、回放自己的录音，最后做小测。

录音只在当前页面中临时使用。学习进度只保存在当前浏览器的本地存储里。Safari 与主屏幕应用的记录不会自动同步；建议先添加到主屏幕再开始学习。

语音识别是关键词匹配参考，不能判断具体音素、口型或重音。它可能需要网络，且兼容性取决于 iOS 版本；若主屏幕应用里无法识别，可以用 Safari 打开同一网址继续练习。朗读、录音回放与小测不需要付费 API。

## 本地预览

在此目录运行 `python -m http.server 8765`，然后访问 `http://127.0.0.1:8765/`。手机使用麦克风时需从 HTTPS 站点访问。
